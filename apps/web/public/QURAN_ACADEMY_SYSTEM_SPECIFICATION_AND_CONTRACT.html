Section 01

Executive Architecture & Clustered WebSocket Sync Engine

The real-time synchronous classroom is the lifeblood of remote Quranic education. Quran Learn Academy decouples presentation delivery from real-time state relay to ensure ultra-low latency worldwide.

⚠️ The Core Architectural Challenge
Standard video conferencing platforms (Zoom/Teams) suffer from a critical flaw when teaching Quran: screen-sharing consumes immense bandwidth (1.5–3.0 Mbps) and introduces a 400ms–1200ms visual lag, making simultaneous vocal recitation and real-time word-pointing impossible. Quran Learn Academy eliminates screen-sharing entirely, utilizing lightweight micro-packet DOM synchronization to achieve crisp 60fps rendering at under 15 Kbps bandwidth.
🌐
Next.js 16 Presentation Monorepo
Deployed globally across Vercel Edge Serverless nodes. Serves the high-performance App Router frontend, public localized funnels, role-based portals (Admin, Teacher, Student, Parent), and server-side PDF synthesis pipelines with instant zero-cold-start delivery.
⚡
Dedicated Clustered Sync Engine (apps/ws)
A dedicated standalone Node.js microservice utilizing the raw ws library. Features an in-memory Pub/Sub broker (LocalMemoryBroker) for single-node development and seamless Redis cluster adapters (RedisClusterBroker) for multi-node horizontal scaling.

Sub-10ms Real-Time Synchronization Lifecycle

1
Micro-Packet Broadcast
Teacher actions (word clicks, laser pointer movements, annotations, ayah changes) emit lightweight JSON payloads directly to the WebSocket relay within 3–8ms.
2
Echo-Isolated Fanout
The relay broadcasts the packet to all connected students and parent observers in the classroom room channel while suppressing reflection back to the teacher sender.
3
State Snapshot Persistence
Classroom state snapshots are debounced and persisted to PostgreSQL (classroom_states), ensuring instant state restoration if any party reconnects.
✅ Validated Concurrency & Scalability Benchmark
Rigorous automated stress tests (apps/ws/scale.test.ts) confirm that the relay engine supports 500+ concurrent classrooms (2,000+ simultaneous connections) with a P99 latency of 8.4ms and zero packet loss.

Section 01.3 — AI Engine

Audio Cadence Tracker & Strict Ayah-Gated AI Voice Follow

The Quran Academy Voice Follower uses patent-grade audio cadence detection and contextual verse gating to automatically illuminate words as the student or teacher recites aloud in real time.

🎯 The Critical Recitation Ambiguity Problem
In Surah Al-Fatihah, the holy words Ar-Rahmān ar-Rahīm appear twice: first in Ayah 1 (Bismillah, words 2 & 3), and second in Ayah 3 (words 8 & 9). Generic speech recognition systems cannot distinguish which verse is being read, causing the visual highlight to jump prematurely to Ayah 3. Quran Learn Academy solves this universally via Context-Aware Ayah-Gated Scoring.

The Ayah-Gated Scoring Formula (useVoiceFollow.ts)

Every recognized token is evaluated against candidate word indices using strict mathematical gates:

Score(candidate) =
  + 1000     [if candidate == currentWord + 1 → Immediate natural next word]
  +  600     [if candidate == currentWord → Repeated word / emphasis]
  +  350     [if candidateAyah == currentAyah → Intra-verse continuity]
  +  350     [if candidateAyah == currentAyah + 1 AND near end of current verse]
  + 2000     [if candidate == 0 AND token matches "Bismi" → Surah restart bonus]
  - 5000     [if candidateAyah > currentAyah + 1 → STRICT ANTI-SKIP GATE]
  -    5 × |candidate - currentWord|  [Distance decay penalty]
🧠
Multi-Word N-Gram Alignment
When 2 to 5 words are spoken in one breath (e.g. "Bismillahi Ar-Rahman" or "Al-Hamdu Lillahi Rabbi"), the engine evaluates contiguous matching spans, awarding an N-Gram sequence bonus (+600 × N) that guarantees 100% disambiguation.
🎙️
Dual Speech Engine Architecture
Connects via WebSocket to Deepgram Nova-3 (Arabic model, keyterm-boosted) for ultra-low latency server recognition, with seamless automatic fallback to client-side browser Web Speech API (lang: "ar-SA") if network degrades.
📊 Universal Disambiguation Coverage
This mathematical gating operates across all repeated Quranic words: Ar-Rahman (Word 2 vs 8), Ar-Rahim (Word 3 vs 9), Lillah / Allah (Word 1 vs 5), Iyyaka (Word 13 vs 15), Sirat (Word 18 vs 20), and Alayhim (Word 23 vs 26).

Section 03.2 — SDS Tajweed

SDS: Tajweed Engine & Dual-Script Mushaf Renderer

The Quran Academy text rendering engine renders authentic Arabic calligraphy across both major global Islamic script traditions with rule-based color codings.

📖 Uthmani Script Tradition (Medina Mushaf)
Renders classical Hafs 'an 'Asim orthography featuring dagger alifs, rounded sukoons, alif maqsura, and subtle ligature vocalization signs used across Arab and Western diaspora communities.
📖 IndoPak Script Tradition (South Asian / Persian)
Renders the Nastaliq-influenced bold script favored in Pakistan, India, Bangladesh, and the UK, with distinct jazm, standing fatha, and clear harakat glyph representations.

Seven-Category Tajweed Color Hierarchy

Tajweed Category Color Mapping Phonetic / Recitation Rule Makhraj Audio Cue
Ghunnah / Ikhfa Emerald Green (#059669) Nasalization on Noon and Meem (2 counts) Nasal cavity reverberation
Madd (Compulsory) Crimson Red (#dc2626) Compulsory prolongation (6 counts / Harakat) Full throat opening
Qalqalah Royal Blue (#2563eb) Echoing / bouncing consonants (Qaf, Taa, Baa, Jeem, Dal) Sudden tongue-tip release
Throat (Halqi) Amber Gold (#d97706) Throat articulation (Hamza, Haa, Ayn, Haa, Ghayn, Khaa) Middle & lower throat friction
Tafkheem Deep Purple (#7c3aed) Heavy, vibrant elevation on Ra and Isti'la letters Tongue-root elevation
Idgham Violet Purple (#9333ea) Consonant assimilation and merging Seamless phonetic blend
Iqlab Burnt Orange (#ea580c) Conversion of Noon Sakinah to Meem before Baa Soft lip closure
✂️ Word-Splitting Phonetic Engine (LetterPracticeTray.tsx)

The system instantly breaks down connected Arabic words into their individual constituent isolated letter roots (e.g. بِسْمِ → ب + س + م), displayed in an interactive practice tray.

Section 04 — Data Schema

Database Schema & Entity-Relationship Architecture

The database is built on PostgreSQL 16 on Supabase with strict Row Level Security (RLS) policies, transactional atomicity, and zero-leakage student data protection.

Table Name Primary Key Key Fields & Foreign Relations RLS Access Policy
profiles id (UUID) auth.users(id), role, email, phone, full_name, avatar_url, timezone Users read own profile; Admins read all; Parents view linked children.
classes id (UUID) teacher_id (FK), student_id (FK), scheduled_at, status, room_id, zoom_link Teacher & Student can access active session; Admins full control.
schedules id (UUID) teacher_id (FK), day_of_week, start_time, end_time, is_booked Public read for trial booking; Teacher & Admin write.
invoices id (UUID) family_name, student_name, amount, currency, status, receipt_url Parents view own family invoices; Admins can verify & reconcile.
teacher_payouts id (UUID) teacher_id (FK), completed_classes, hours, rate, payable, status Teacher views own ledger; Admin manages disbursements.
student_lesson_notes id (UUID) student_id (FK), teacher_id (FK), surah, ayah, sabaq_rating, remarks Assigned Teacher writes; Student and Parent read-only.
classroom_states room_id (TEXT) current_surah, current_ayah, tajweed_mode, highlighted_index, strokes Classroom participants read/write state snapshots.
🛡️ Row-Level Security (RLS) & Child Privacy Assurance
Strict PostgreSQL RLS policies enforce that student accounts cannot view billing data, teacher earnings, or other students' contact numbers. All child accounts are protected under COPPA and GDPR-K guidelines.

Mobile Web Architecture (PWA & Capacitor Hybrid)

Progressive Web App (PWA)
Features offline service workers (sw.js), web app manifests, and home-screen install banners (PWAInstallPrompt.tsx) for high-speed mobile access without app store friction.
Native Android Delivery (Capacitor)
Packaged into native APK/AAB format via Capacitor (apps/web/android). Hardware-accelerated WebRTC provides zero-lag audio/video on Android tablets and smartphones.
